    How this forecast works

    Each check reads the global weather models run by ECMWF (Europe), NOAA (United States), DWD (Germany) and Environment and Climate Change Canada, plus two long-range ensembles that run each forecast dozens of times. Values outside realistic ranges are discarded, and so is any model that disagrees with the others by more than 5°. The result is blended with 15 years of NOAA daily records from Los Cabos International Airport and Cabo San Lucas. Far from the date, the blend leans on those records. Closer in, it leans on the models.
